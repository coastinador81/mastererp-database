# mastererp-database
Modelo de datos, migraciones y seeds de MasterERP.

```
mastererp-database/
├── schema/                  Modelo y definiciones de datos.
├── migrations/              Cambios versionados de base de datos.
├── seeds/                   Datos iniciales o de prueba.
└── documentation/           Diccionario de datos y decisiones asociadas.
```
